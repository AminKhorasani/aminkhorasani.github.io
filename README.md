# aminkhorasani.github.io

Personal portfolio of **Amin Khorasani** — Data, AI, Analytics & Product Engineering.

## Live site

https://aminkhorasani.github.io/

## Stack

A deliberately simple static site:

- HTML
- CSS
- Vanilla JavaScript
- GitHub Pages

No build step, framework, or package install is required.

## Local preview

Open `index.html` directly, or run any static server, for example:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Content

Public portfolio content only. Private company data, internal dashboards, SQL, and confidential project details are intentionally excluded.
